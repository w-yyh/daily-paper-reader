## 摘要
开放世界目标检测（OWOD）要求检测器识别已知类别，发现来自未知类别的未命名物体，并增量学习新标注的类别。PROB通过在解码器查询空间中对类别无关的概率目标性进行建模，提高了对未知物体的发现能力。然而，仅靠视觉目标性无法确定一个类似目标的查询对应于一个困难的已知实例、一个未知类别物体还是背景杂波，这导致了模糊的已知-未知决策边界。我们提出MSPO，一个轻量级语义校准框架，它在保留PROB的检测器架构和增量学习方案的同时，为其增加了任务感知的已知类别语言先验。对于每个当前已知类别，MSPO构建一个涵盖类别属性、视觉外观、典型场景和功能用途的扩展文本描述，并使用冻结的CLIP文本编码器对其进行编码。解码器查询特征被投影到相同的语义空间中，以估计它们从当前已知类别语义中获得的支持。这种语义证据与PROB的视觉目标性相融合，以校准已知和未知的预测，而不会将OWOD转变为开放词汇分类。重要的是，MSPO从未使用未来类别名称，并且在评估过程中所有未知类别均保持未命名状态。在M-OWODB和S-OWODB上的实验表明，MSPO在主要聚合指标上改进了强大的PROB基线，同时保持了有竞争力的未知召回率。它还改善了早期未知混淆指标，并将PASCAL VOC的最终mAP提高了最多2.7个百分点。这些结果表明，在标准OWOD设置下，已知类别的语言语义为概率目标性提供了有效的校准信号。

## Abstract
Open-world object detection (OWOD) requires a detector to recognize known categories, discover unnamed objects from unseen categories, and incrementally learn newly annotated classes. PROB improves unknown discovery by modeling class-agnostic probabilistic objectness in the decoder-query space. However, visual objectness alone cannot determine whether an object-like query corresponds to a hard known instance, an unseen-category object, or background clutter, resulting in an ambiguous known-unknown decision boundary. We propose MSPO, a lightweight semantic calibration framework that augments PROB with task-aware known-category language priors while preserving its detector architecture and incremental learning protocol. For each currently known category, MSPO constructs an extended text description covering category attributes, visual appearance, typical scenes, and functional usage, and encodes it using a frozen CLIP text encoder. Decoder query features are projected into the same semantic space to estimate their support from the current known-category semantics. This semantic evidence is fused with PROB's visual objectness to calibrate known and unknown predictions without turning OWOD into open-vocabulary classification. Importantly, MSPO never uses future-category names, and all unseen categories remain unnamed during evaluation. Experiments on M-OWODB and S-OWODB show that MSPO improves the strong PROB baseline on the main aggregate metrics while retaining competitive unknown recall. It also improves early unknown-confusion metrics and raises PASCAL VOC final mAP by up to 2.7 points. These results demonstrate that known-category language semantics provide an effective calibration signal for probabilistic objectness under the standard OWOD setting.

## 2. 论文提出的方法论

- **核心思想**  
  在PROB的概率目标性模型中，未知物体应具有高视觉目标性，但缺乏来自已知类别的语义支持。MSPO利用冻结的CLIP文本编码器为每个当前已知类别生成扩展文本描述（Extended-Text Embeddings），并将解码器查询特征投影到相同的语义空间，计算每个查询的“已知语义支持度”。通过将语义支持度低而视觉目标性高的查询识别为潜在未知物体，从而优化已知/未知/背景的决策边界。

- **关键技术细节与流程**
  1. **语义扩展文本提示（Semantic Extended Text Prompt）**  
     对每个已知类别 \(c \in C_{\text{seen}}^t\)，构造固定格式的扩展文本提示：
     > “a photo of \{label\}, with \{attributes\}, appearing as \{appearance\}, often seen in \{scene\}, and used for \{function\}.”  
     利用冻结的CLIP文本编码器 \(E_{\text{txt}}\) 将其映射为归一化的文本嵌入向量 \(\mathbf{p}_c\)，堆叠得到已知类别语义锚点矩阵 \(\mathbf{P} \in \mathbb{R}^{K \times D_t}\)。该描述仅在当前已知类别上构建，未来类别名称不会被使用。

  2. **语义投影与查询-文本对齐（Semantic Projection and Query-Text Alignment）**  
     - 检测器的解码器查询特征 \(\mathbf{Q} \in \mathbb{R}^{N \times D_q}\) 通过一个轻量级的投影头 \(g\)（两层MLP + ReLU + Dropout）映射到CLIP文本嵌入空间：\(\mathbf{h}_i = g(\mathbf{q}_i) / \|g(\mathbf{q}_i)\|_2\)。
     - 计算查询与已知类别文本原型之间的语义逻辑值（logits）：\(a_{i,c} = \mathbf{h}_i^\top \mathbf{p}_c / \gamma_s\)，其中 \(\gamma_s\) 为语义温度。
     - 对有真实框匹配的查询施加交叉熵损失 \(\mathcal{L}_{\text{sem}}\)，使查询特征与已知类别语义对齐。未匹配的背景查询不施加语义标签，以避免干扰潜在的未知物体。

  3. **语义-概率目标性融合（SPOF）**  
     - PROB原有的视觉目标性证据：\(V_i = \exp(-\tau \, d_i^{\text{PROB}})\)，其中 \(d_i^{\text{PROB}}\) 是查询 \(\mathbf{q}_i\) 到类无关物体特征分布的Mahalanobis距离。
     - 已知语义支持度 \(K_i^{\text{sem}}\) 通过组合当前已知类别的softmax最大值和绝对亲和度得到，其补数即为 **语义拒绝项** \(R_i^{\text{sem}} = 1 - K_i^{\text{sem}}\)。
     - 未知感知的目标性线索定义为：\(U_i^{\text{SPOF}} = V_i \cdot R_i^{\text{sem}}\)。此乘积使已知物体（高 \(V_i\)、低 \(R_i^{\text{sem}}\)）和未知物体（高 \(V_i\)、高 \(R_i^{\text{sem}}\)）与背景（低 \(V_i\)）得以分离。
     - 训练时，利用匹配的已知物体来监督学习目标性边界，构造融合距离 \(D_i^{\text{SPOF}} = d_i^{\text{PROB}} + \lambda_s R_i^{\text{sem}}\)，并最小化平均距离 \(\mathcal{L}_{\text{obj}}\)，从而引导已知物体的视觉距离变小且语义支持变大。

  4. **总体目标函数**  
     \(\mathcal{L} = \mathcal{L}_{\text{cls}} + \lambda_1 \mathcal{L}_{\text{box}} + \lambda_2 \mathcal{L}_{\text{sem}} + \lambda_3 \mathcal{L}_{\text{obj}}\)。  
     通过独立权重控制语义对齐和语义融合的贡献，可实现模块化消融。

- **关键设计原则**  
  整个框架严格遵循OWOD协议：未使用未来类别名称，未知物体始终以单一“unknown”标签报告；所有语义组件可独立启停，便于分析。

## 6. 论文的主要结论与发现

- MSPO在不改变PROB检测器架构和OWOD协议的前提下，通过已知类别的语言语义校准，能有效改善已知/未知/背景的辨识能力。
- 在M-OWODB和S-OWODB上，MSPO在聚合指标（如Task的Both AP、最终mAP）上普遍优于PROB，其中S-OWODB上平均提升约0.8点，PASCAL VOC增量场景下最终mAP最高提升2.7点。
- 语义校准主要增强了早期已知类识别精度和整体已知-未知权衡，而非均一地提升所有子指标；未知召回率基本保持或略有改善。
- 未知混淆指标（WI、A-OSE）在早期任务中有所降低，说明早期已知-未知决策边界变得更清晰。
- 消融实验表明，仅用简单类别名称（无扩展描述）反而可能降低性能，扩展文本描述和语义-概率融合二者结合才能达到最佳效果。
