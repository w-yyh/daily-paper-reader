## 摘要
开放世界目标检测要求模型能够识别已知类别、拒绝不熟悉的对象，并随时间整合新类别。在数据稀缺的场景（如生物医学和科学成像）中尤为困难，因为稀有类别可能只有少量标注样本，细粒度类别仅通过细微形态差异区分。基于原型的检测器天然适合这种情况，但它们通常将类原型学习为独立的锚点，忽视了类别间的关系结构。我们提出类别几何监督（CGS），这是一个通用框架，约束学习到的原型或类别表示空间，以保留从训练数据中估计的视觉或语义类别不相似度。CGS 引入了一个保持不相似度的目标，将学习到的类别表示之间的成对距离与目标类别几何矩阵对齐，同时保留标准任务损失。我们在原型识别、少样本生物医学目标检测、开放集检测、新类别插入以及 COCO 上的开放世界目标检测（OWOD）适配中对同一目标进行了实例化。实验表明，CGS 提高了识别和 OVA 检测中的样本效率，显著加强了新类别插入，并在 COCO 上提高了未知类别召回率，同时保留了大量已知类别检测性能。消融实验表明，有意义的视觉几何提供了最可靠的增益，而随机几何有助于新类别分离，但在少样本检测中一致性较差。这些结果表明，关系型类别几何是在有限监督下构建校准良好且可扩展的开放世界检测器的有效监督信号。

## Abstract
Open-world object detection requires models to recognize known categories, reject unfamiliar objects, and incorporate new classes over time. This is especially challenging in scarce-data settings such as biomedical and scientific imaging, where rare categories may have only a few annotated examples and fine-grained classes differ by subtle morphology. Prototype-based detectors are natural for this regime, but they typically learn class prototypes as independent anchors, ignoring relational structure among classes. We propose class-geometry supervision (CGS), a general framework that constrains learned prototype or class-representation spaces to preserve visual or semantic class dissimilarities estimated from training data. CGS introduces a dissimilarity-preserving objective that aligns pairwise distances among learned class representations with a target class-geometry matrix while retaining the standard task loss. We instantiate the same objective across prototype recognition, few-shot biomedical object detection, open-set detection, novel-class insertion, and OWOD adaptation on COCO. Experiments show that CGS improves sample efficiency in recognition and ova detection, substantially strengthens novel-class insertion, and improves unknown recall on COCO while retaining much of the known-class detection performance. Ablations show that meaningful visual geometry provides the most reliable gains, while random geometry can help novel separation but is less consistent for few-shot detection. These results suggest that relational class geometry is an effective supervisory signal for building calibrated and extensible open-world detectors under limited supervision.

## 1. 论文的核心问题与整体含义

- **研究背景**：开放世界目标检测要求模型同时完成三项任务——识别已知类别、拒绝未知对象、随时间动态插入新类别。在生物医学和科学成像等稀缺数据场景中，这一目标尤为困难：稀有类别可能只有几张标注样本，细粒度类别仅凭细微形态差异区分，且无法依赖大规模重训练。
- **核心问题**：现有基于原型的检测器（如 ProtoNet、FSP-DETR）把每个类原型视为独立锚点，仅通过任务损失拉开类间距离，忽视了类别之间本身存在的关系结构。这种独立性导致原型空间校准不良：视觉相似类别可能被任意分离，不相似类别可能坍塌，进而影响未知拒绝和新类插入。
- **整体含义**：论文提出利用“类别几何”（class geometry）这一额外监督信号，约束原型空间保持类别间的视觉或语义不相似度关系，从而在有限监督下提升开放世界检测的样本效率、未知召回和新类整合能力。

## 2. 论文提出的方法论

- **核心思想**：类别几何监督（Class-Geometry Supervision, CGS）通过不相似度保持目标，将学习到的类原型之间的成对距离矩阵 \(G\) 与从训练数据估计的目标类别不相似度矩阵 \(D\) 对齐，同时保留标准任务损失。
- **目标几何矩阵构建**：
  - 视觉几何：\(D^{\text{vis}}_{ij}\) 由两类支持区域裁剪图像的像素级平均 MSE 计算，捕捉粗粒度形态差异。
  - 语义/文本几何：\(D^{\text{txt}}_{ij} = 1 - \cos(e_i, e_j)\)，其中 \(e_i\)、\(e_j\) 为类别视觉描述文本的嵌入（如 MPNet 对 Gemini 生成描述的嵌入）。
- **损失函数**：
  - 学习原型距离矩阵 \(G_{ij} = d(p_i, p_j)\)，\(d\) 为欧氏或余弦距离。
  - 对 \(G\) 和 \(D\) 的 off-diagonal 条目做标准化：\(\hat{G}_{ij} = (G_{ij} - \mu_G)/\sigma_G\)，\(\hat{D}_{ij} = (D_{ij} - \mu_D)/\sigma_D\)。
  - 类别几何损失：\(L_{CG} = \frac{1}{|E|} \sum_{(i,j) \in E} (\hat{G}_{ij} - \hat{D}_{ij})^2\)，其中 \(E\) 为所有类对。
  - 总目标：\(L = L_{\text{task}} + \lambda L_{CG}\)。
- **理论性质**：
  - 命题1：若 \(L_{CG} \le \epsilon\)，则学习原型图与目标类不相似度图的平均绝对失真 ≤ \(\sqrt{\epsilon}\)。
  - 命题2：若目标几何中类 \(j\) 比类 \(k\) 更接近类 \(i\) 且边距为 \(\gamma\)，当学习原型距离失真 ≤ \(\gamma/2\) 时，学习空间保持邻域顺序。
  - 这解释了 CGS 控制图失真并支持邻域保留，尤其利于新类插入。
- **开放世界决策**：
  - 给定查询区域特征 \(z\)，预测标签为 \(\arg\min_c d(z, p_c)\)。
  - 未知分数为最近原型距离 \(m(z) = \min_c d(z, p_c)\)，若超过阈值 \(\tau_{\text{unk}}\) 则标记为未知。
  - 新类插入：新增类别原型加入现有原型集，扩展几何矩阵，新原型根据与已有类别的视觉/语义关系放置在合适位置。
- **算法流程**（Algorithm 1）：
  1. 标准化目标不相似度矩阵 \(D\) 得到 \(\hat{D}\)；
  2. 每个训练 episode/minibatch 计算支持类原型 \(p_c\)；
  3. 构造学习原型距离矩阵 \(G\) 并标准化为 \(\hat{G}\)；
  4. 计算 \(L_{CG}\)；
  5. 最小化 \(L_{\text{task}} + \lambda L_{CG}\) 更新参数；
  6. 使用最终原型集进行最近原型预测、未知拒绝或新类插入。
- **三种应用实例**：
  - 原型识别（ProtoNet 风格）：在标准原型匹配损失上加入 CGS。
  - 原型生物医学检测：DETR 检测器，目标 \(L = L_{\text{det}} + L_{\text{proto}} + \lambda L_{CG}\)，用于少样本 OVA 检测、开放集检测和 15-to-20 类增量学习。
  - 开放世界检测器适配（OW-DETR/COCO）：冻结头部微调分类 MLP，或全模型微调。

## 6. 论文的主要结论与发现

- CGS 在低样本识别和 OVA 检测中一致提升性能，且在最低样本设置下增益最大，表明类别几何在原型估计稀缺时提供有效额外监督。
- 在少样本 OVA 检测中，FSP-DETR + CGS 将 5-shot mAP 从 0.066 提升至 0.076，10-shot 从 0.094 提升至 0.102；开放集 mAP 从 0.045 提升至 0.061。
- 新类插入收益最大：novel-only mAP 从 0.0629 提升至 0.1558，generalized novel mAP 从 0.0569 提升至 0.1348，且 seen retention 也有提升。
- COCO OWOD 上 CGS 提高未知召回，尤其冻结头部设置提升显著，但伴随已知类 mAP 下降；全模型微调可降低该权衡，保留更多已知类性能。
- 几何源消融显示：视觉几何最可靠；文本几何也有提升；随机几何对 novel separation 有帮助但一致性差。
- 总体结论：关系类别几何是构建校准、可扩展开放世界检测器的有效监督信号。

## 7. 优点

- **方法简单通用**：只需在原型学习目标上增加一个成对距离保持损失，无需修改检测器架构，可应用于识别、检测和 OWOD 适配。
- **理论支撑清晰**：用两个命题说明 CGS 控制平均图失真并保留邻域顺序，增强方法可信度。
- **多任务验证**：覆盖识别、少样本检测、开放集、新类插入、COCO OWOD，且跨生物医学和自然图像，迁移性有证据。
- **消融严谨**：对比视觉、文本、随机几何，揭示“有意义几何”的作用，随机几何仅提供分离效果。
- **突出新类插入场景**：实验表明 CGS 在增量类别插入上提升显著，契合开放世界的核心需求。
- **可解释性较好**：通过原型空间几何和距离阈值决策，使未知拒绝与类别关系清晰关联。

## 8. 不足与局限

- **已知类 mAP 权衡**：COCO 冻结头部 CGS 显著提升未知召回但降低已知类 mAP；虽然全模型微调缓解，但方法本质是牺牲部分闭集精度换取开放集敏感性。
- **几何源依赖强**：
  - 视觉几何基于像素 MSE，对形态差异敏感但可能受背景、光照等干扰；
  - 文本几何依赖生成的描述质量和嵌入模型；
  - 视觉与语义几何不一致时如何处理尚未解决。
- **随机几何的不可靠性**：随机几何虽能帮助新类分离，但缺乏一致性和可解释性，说明 CGS 的性能高度依赖目标几何质量。
- **实验覆盖局限**：
  - 仅在一个生物医学 OVA 数据集和 COCO 上验证，其他领域（如病理、天文、工业缺陷）泛化性未测试；
  - COCO 对比主要与 OW-DETR 受控比较，缺少与更多基线在 CGS 下的完整对比；
  - 阈值 \(\tau_{\text{unk}}\) 依赖验证集选择，可能影响跨域鲁棒性。
- **增量学习机制未深入**：文中新类插入主要涉及“加入新原型而不重训旧原型”，但未系统研究长期增量下旧类灾难性遗忘或原型漂移。
- **理论边界有限**：命题仅说明平均失真和局部邻域保留，未给出未知检测性能的显式保障。
